```text
Given an integer array nums, return all the triplets [nums[i], nums[j], nums[k]] such that i != j, i != k, and j != k, and nums[i] + nums[j] + nums[k] == 0.
Notice that the solution set must not contain duplicate triplets.
Example 1:
Input: nums = [-1,0,1,2,-1,-4]
Output: [[-1,-1,2],[-1,0,1]]
Explanation: 
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0.
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0.
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0.
The distinct triplets are [-1,0,1] and [-1,-1,2].
Notice that the order of the output and the order of the triplets does not matter.

Hints -  
Sort - it will help to pass values already encountered such that i != j, i != k, and j != k
2 pointer - here we fix i with loop, 2 pointer for j and k with l and r
```
        
```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        Arrays.sort(nums);
        
        for(int i=0; i+2<nums.length; i++){
            if(nums[i]>0)break;  // ignore invalid values
            if(i>0 && nums[i]==nums[i-1])continue;  // avoid duplicates for i

            int l=i+1, r=nums.length-1;
            while(l<r){
                int sum = nums[i]+ nums[l]+nums[r];
                if(sum>0)r--;
                else if(sum<0)l++;
                else{
                    res.add(Arrays.asList(nums[i], nums[l],nums[r]));
                    l++;r--;
                    while(l<r &&  nums[l]==nums[l-1]) l++;  // avoid duplicates  for l
                }
            }
        }
        return res;
    }
}
```

**Time complexity:** $O(n^2)$

- Sorting takes $O(n \log n)$.
- The outer loop runs $O(n)$ times.
- For each fixed `i`, the two-pointer scan moves `l` and `r` across the array in $O(n)$ time.
- Total: $O(n \log n + n^2) = O(n^2)$.

**Space complexity:**

- Auxiliary space: $O(1)$, excluding the result list. Sorting the primitive `int[]` is in-place.
- Result storage: $O(k)$, where $k$ is the number of triplets returned.

So the overall complexity is:

```text
Time:  O(n^2)
Space: O(1) auxiliary, or O(k) including output
```
